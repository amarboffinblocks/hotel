# The Grandview Hotel & Resort

Phase 1 frontend — Next.js App Router, Tailwind CSS v4, shadcn/ui.

## Stack

- Next.js 16 + TypeScript
- Tailwind + shadcn/ui
- Design system from `DESIGN.md` (forest green, gold, ivory)
- Fonts: Playfair Display + Plus Jakarta Sans
- Mock data in `src/data/` (MongoDB + Cloudinary later)

## Scripts

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Phase roadmap

1. **Frontend (current)** — marketing site + booking UI with mock data
2. **Admin dashboard** — manage rooms, offers, reviews
3. **Backend** — MongoDB + Cloudinary + real availability
